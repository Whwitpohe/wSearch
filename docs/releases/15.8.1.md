## 中文

wSearch 15.8.1 是本项目的首个正式版本。Windows x64 于 2026-11-25 发布，macOS 和 Linux 安装包于 2026-11-26 补齐。

### 功能与改进

- **整图翻译**。将框选截图发送给自己配置的 OpenAI 兼容、Anthropic 或 Gemini 视觉模型，译文会覆盖在对应文字的位置。
- **框选后执行**。为翻译、画笔、复制和保存分别绑定快捷键，在支持搜索的分组选择器中切换动作。
- **设置与界面**。OCR 引擎与配置面板联动，代理字段随模式切换。设置、运行日志和 AI 输入区支持深浅主题，Windows 11 主窗口可使用 Mica 材质。
- **性能**。文本翻译按需加载语言识别模型；连续屏幕翻译等待上一轮完成再刷新；录屏提示减少重复的进程间通信。

## English

wSearch 15.8.1 is the project's first stable release. The Windows x64 installer shipped on November 25, 2026. The macOS and Linux packages followed on November 26, 2026.

### Features and improvements

- **In-place image translation.** Send a selected screenshot to your configured OpenAI-compatible, Anthropic or Gemini vision model. The translation appears where the original text was.
- **Actions after selection.** Assign separate shortcuts to translation, drawing, copying and saving. Find an action in the searchable, grouped picker.
- **Settings and interface.** Selecting an OCR engine opens its configuration. Proxy settings show the fields for the selected mode. Settings, the application log and the AI composer support light and dark themes. Main windows on Windows 11 can use Mica.
- **Performance.** Text translation loads the language detector on demand. Continuous screen translation waits for the previous pass to finish. The recording overlay sends fewer duplicate messages between processes.

### Downloads and installation

| Platform | Processor | Formats |
| --- | --- | --- |
| Windows | x64 | EXE |
| macOS | Apple Silicon (ARM64), Intel (x64) | DMG, ZIP |
| Linux | x64, ARM64 | AppImage, DEB, RPM, tar.gz |

The Windows installer uses a separate wSearch application ID and can reuse an existing eSearch configuration on first launch. The Windows EXE has no Authenticode signature. The macOS packages have no Apple Developer ID signature or notarization. Both macOS ZIPs and both Linux tar.gz archives were extracted and started on runners matching their processor architecture. All four reported version `15.8.1`.
