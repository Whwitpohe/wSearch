## 中文

- 标准版在首次使用本地 OCR 时下载模型，之后可断网使用。需要从第一次启动就离线识别，请下载文件名带 `-offline` 的版本。
- OCR 在最后一次识别结束 30 秒后释放模型会话。Bergamot 本地翻译在空闲两分钟后结束工作线程，下次使用时重新加载。
- 截图窗口预热取屏和拖框，标注和长截图按需加载。自动框选支持 RGB 差分和 Canny 边缘检测。
- 截图翻译支持原位覆盖、并排对照和目标语言快捷选择。可分别复制原文、译文、原图、译图或对照图。点击编辑后，译图保留当前位置和大小，周围桌面继续可见。
- 多显示器贴图按需创建覆盖窗口，支持跨屏拖动。

Windows 使用 EXE 或 ZIP，macOS 使用 DMG 或 ZIP，Linux 提供 AppImage、DEB、RPM 和 tar.gz。请选择与设备处理器匹配的文件。各文件的 SHA-256 见本次发布所附的 `SHA256SUMS.txt`。

## English

- The standard edition downloads local OCR models on first use and caches them for offline recognition. Choose a package with `-offline` in its name for offline OCR from the first launch.
- Local OCR releases its model sessions after 30 seconds of inactivity. The Bergamot translation worker exits after two idle minutes. Both reload on demand.
- The capture window keeps screen capture and region selection ready. Annotation and scrolling capture load on demand. Automatic selection supports RGB differencing and Canny edge detection.
- Screenshot translation supports overlays, side-by-side comparison and quick language selection. Copy the source text, translation, original image, translated image or both images together. Opening the editor keeps the translated image in place with the surrounding desktop visible.
- Pin overlays open on the displays that need them and follow pins dragged across monitors.

Choose the file for your processor. Windows packages come in EXE and ZIP formats, macOS packages in DMG and ZIP, and Linux packages in AppImage, DEB, RPM and tar.gz. File hashes are included in `SHA256SUMS.txt`.
